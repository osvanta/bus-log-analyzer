# Keyboard shortcuts

**Help ▸ Keyboard shortcuts** shows the same list inside the application.

## The work, step by step

| Key | Action |
|---|---|
| ++f1++ | Open this guide's Getting started page |
| ++ctrl+o++ | Open Measurement |
| ++f9++ | Decode: read the measurement and decode it into signals |
| ++ctrl+s++ | Save configuration |
| ++ctrl+e++ | Export plotted signals |
| ++ctrl+shift+r++ | Open the Trace: the raw CAN and LIN frames |

## Calculated Signal

| Key | Action |
|---|---|
| ++shift+f3++ | Insert function: every function, operator and constant, with how to use each |

## Signal tree

| Key | Action |
|---|---|
| ++space++ | Plot the selected signals |
| ++ctrl+shift+minus++ | Collapse every message |
| ++ctrl+shift+plus++ | Expand every message |

## Plot

| Key | Action |
|---|---|
| ++f++ | Fit to Window: the whole recording, in time and height |
| ++v++ | Fit Vertical: the height only, keeping the time range |
| ++s++ | Step Mode or Interpolation Mode: each value held until the next sample, or straight lines between samples |
| ++c++ | Change the colour of the selected signal |
| ++delete++ | Remove the selected signal from the plot |
| ++ctrl+z++ | Undo the last plot action, up to three times |

## Cursors

| Key or mouse | Action |
|---|---|
| ++r++ | Switch Cursor 1 and Cursor 2 on or off together |
| Click on the plot | Place Cursor 1 there, switching it on if it is off |
| ++shift+++click on the plot | Place Cursor 2 there, switching it on if it is off |

## Rectangle Zoom

| Key or mouse | Action |
|---|---|
| ++z++ | Switch Rectangle Zoom on or off |
| Drag on the plot | Zoom into the box |
| ++shift+++drag on the plot | Zoom out around the box; a smaller box zooms out further |
| Double-click on the plot | Fit to Window: the whole recording |
| ++esc++ | Leave Rectangle Zoom |
